## 🚀 Como executar o projeto

### Pré-requisitos

- .NET 8 SDK
- Node.js + Angular CLI
- SQL Server

### Passos

1. Clonar o repositório
2. Executar `update-database` na camada de infraestrutura
3. Iniciar a API (`dotnet run`)
4. Entrar no frontend: `cd frontend` e `npm install`
5. Rodar a aplicação Angular: `ng serve`
